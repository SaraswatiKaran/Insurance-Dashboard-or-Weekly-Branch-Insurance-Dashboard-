# Insurance-Dashboard-or-Weekly-Branch-Insurance-Dashboard-
An interactive Insurance Analytics Dashboard built with SQL and Tableau to evaluate weekly branch performance. Features target vs. actual tracking for New Business, Renewals, and Cross-Sell metrics, agent meeting trends, and income distribution funnels to streamline executive reporting.
## Project Objective

The objective of this project is to create a weekly branch insurance performance report. This enables business stakeholders to evaluate sales targets, monitor agent performance, and understand branch revenue drivers to optimize operations.

## Tech Stack & Dataset Used

* **SQL**: Data querying, extraction, and transformation
* **Tableau**: Interactive dashboard creation and data visualization
* **MS Excel**: Data validation and preliminary analysis

## Key Questions & Analysis (KPIs)

* How do actual sales perform against targets across New Business, Renewals, and Cross-Sell metrics? 
* Which category or product type contributes the highest revenue contribution?
* How do weekly meeting counts vary across different asset types?
* Which months or weeks recorded the highest sales and performance metrics?
* What is the distribution of income across different branch types?
* How do agent performance metrics compare across various branches?
* What does the revenue stage funnel look like from initial prospect to closed deal?
* What is the total number of policies/orders delivered or processed?

## Process / Workflow Steps

- **Requirement Gathering & Metric Identification**: Defined key business KPIs including weekly targets vs. actuals for New Business, Renewals, and Cross-Sell metrics across branch networks.
- **Data Extraction & Transformation (SQL)**: Wrote optimized SQL queries to clean raw database tables, join multi-table schemas, and aggregate branch-level transaction records.
- **Data Validation (MS Excel)**: Reconciled SQL output against source data using Excel pivot tables to ensure numerical accuracy before visualization.
- **Dashboard Design & Data Modeling (Tableau)**: Connected cleaned data sources to Tableau, established data models, and created calculated fields for stage funnels and percentage achievements.
- **Visual Analytics & Formatting**: Built dynamic visual charts—including KPI cards, bar charts for asset distribution, and stage funnels—and customized the layout for executive readability.
- **Documentation & Deployment**: Documented project methodology, formatted repository files, and published the final interactive dashboard for stakeholder review.
